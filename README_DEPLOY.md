# BrightPath Academy — Enterprise Launch Package

## Deploy to Netlify
1. Unzip this package.
2. Drag the extracted folder into Netlify Drop, or deploy the folder via your connected repository.
3. Netlify will serve `index.html` automatically.
4. The enterprise interest form uses Netlify Forms and will appear in your Netlify project after deployment.

## Included
- `index.html` — public enterprise academy website
- `academy.html` — learner portal preview
- `success.html` — form success page
- `assets/` — optimized images, stylesheet, JavaScript and icons
- `netlify.toml` — headers/cache settings
- `site.webmanifest`, `robots.txt`, `404.html`

## Launch note
The public site is fully static and deployable. The learner portal is a polished front-end preview. Real learner authentication, payment, video uploads, assessor workflows and legally issued credential records require a backend/database and are intentionally not simulated as live capabilities.
